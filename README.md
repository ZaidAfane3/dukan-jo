# Seen

A website project, currently in early development.

## Typography

Arabic text uses the **Thmanyah** typeface by default (`thmanyahsans`), with system Arabic fonts as a fallback.

The font files are licensed by thmanyah Publishing and Distribution and may not be redistributed, so they are **not included in this repository**. To work on the project locally, download the family from the official site, [thmanyah.com](https://thmanyah.com), and place the files in a local `fonts/` folder (ignored by git).
